**Skillora — Onboarding UI Design****

**Project Overview**

Skillora is a fictional learning application designed to help users discover new skills, learn from industry experts, and track their learning progress.

This project features a modern, three-screen mobile onboarding experience created for the Pynexia UI/UX Design Internship.

Onboarding Screens

**1. Discover Your Next Skill**

Introduces Skillora and encourages users to explore courses and develop practical skills.

**2. Learn from Experts**

Highlights expert-led learning, mentorship, and practical guidance.

**3. Track Progress and Grow**

Introduces learning progress tracking, weekly goals, and achievements.

**Key Features**

- Three-screen mobile onboarding experience.
- Interactive Next and Skip navigation.
- Pagination indicators.
- Get Started interaction.
- Completion overlay.
- Continue Learning button.
- Smooth prototype transitions.
